# resources/ — datasheets and reference manuals

Three reference PDFs for the STM32G474VEHX target, plus per-PDF indexes generated by `build_index.py`.

| PDF | Pages | TOC entries | Use for |
|---|---|---|---|
| `stm32g474_datasheet.pdf` | 236 | 132 | Pinout, electrical limits, package, peripheral *availability*, ordering |
| `stm32g4_reference_manual.pdf` | 2140 | 2872 | Authoritative register/bitfield definitions, peripheral behavior, memory map |
| `stm32_hrtim_cookbook.pdf` | 84 | 128 | HRTIM application patterns (PWM topologies, ADC triggering, fault handling) |

For each `<name>.pdf` there are two companion files:

- `<name>.toc.md` — markdown outline with PDF page numbers. Scan this first.
- `<name>.txt` — `pdftotext -layout` dump with `=== PAGE N ===` markers between pages. Grep this when you don't already know which section to look at.

PDFs themselves are best for figures, register-bit diagrams, timing charts, and pinout tables — text extraction loses those.

## How to query

**1. If you know roughly what section you want** → open the relevant `.toc.md`, find the page, then read the PDF directly:

```
Read tool: file=resources/stm32g4_reference_manual.pdf, pages="1019-1025"
```

The Read tool accepts up to 20 pages per call. TOC page numbers are 1-based PDF pages — exactly what the `pages` parameter takes.

**2. If you need to find where something is mentioned** → grep the text dump and show the page along with each match:

```bash
awk '/^=== PAGE / {p=$3} /HRTIM_CMP1/ {print "p" p ": " FILENAME ":" NR ": " $0}' \
    resources/stm32g4_reference_manual.txt | head
```

That prints `p<page>: <file>:<line>: <match>`, so you can jump straight from a grep hit to a Read on the right PDF page (for figures/diagrams).

For quick text-only context without opening the PDF, `sed -n '<line-50>,<line+50>p' resources/<name>.txt` shows a window around the hit; the nearest preceding `=== PAGE N ===` marker tells you the page.

**3. If you want a peripheral overview** → start with the datasheet's "Functional overview" (§3, p18) for the high-level wiring, then jump to the RM chapter for register-level detail. The RM chapter list:

- Reset / clock / power: chapters 6–8
- Memory & bus: chapter 2
- DMA / DMAMUX: chapters 12–13
- GPIO: chapter 9
- ADC: chapter 21
- DAC: chapter 22
- HRTIM: chapter 28 (large — register defs in §28.5)
- Basic timers (TIMx): chapters 29–34
- USART/LPUART: chapter 38
- SPI: chapter 40
- FDCAN: chapter 44
- CORDIC: chapter 17
- FMAC: chapter 18
- IWDG/WWDG: chapters 35–36

(For exact starting pages, scan `stm32g4_reference_manual.toc.md` — chapter numbers are in the headings.)

## Regenerating

After adding/replacing a PDF, run:

```bash
python3 resources/build_index.py
```

Requires `pymupdf` (`pip install pymupdf`) and `pdftotext` (poppler-utils). The script overwrites `<name>.toc.md` and `<name>.txt` for every `*.pdf` in this directory.
